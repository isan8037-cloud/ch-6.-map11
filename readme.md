# 부산 지하철 역별 이용객 지도 분석 앱

이 프로젝트는 Streamlit과 Folium을 사용하여 부산 지하철 역별 이용객 수를 지도에 시각화하는 간단한 웹 애플리케이션입니다. 파이썬 기초 및 데이터 시각화 학습 목적으로 제작되었습니다.

## 주요 기능
- **CSV 데이터 업로드**: `busan_subway.csv` 파일을 업로드하여 데이터를 표 형태로 확인합니다.
- **지도 시각화**: Folium을 이용해 부산 지도 위에 지하철 역 위치를 원형 마커로 표시합니다.
- **이용객수 비례 마커**: 마커의 크기(면적)는 각 역의 이용객 수에 비례하여 나타납니다.
- **상호작용**: 마커에 마우스를 올리면 역 이름이, 클릭하면 이용객 수가 팝업으로 표시됩니다.

## 요구 사항
- Python 3.7+
- 자세한 패키지 목록은 `requirements.txt`를 참고하세요.

## 설치 및 실행 방법

1. 프로젝트 저장소를 다운로드합니다.
2. 터미널(또는 명령 프롬프트)을 열고, 프로젝트 폴더로 이동한 후 아래 명령어를 입력하여 필요한 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. 다음 명령어로 Streamlit 앱을 실행합니다.
   ```bash
   streamlit run app.py
   ```

## 데이터 형태 (busan_subway.csv)
앱이 정상적으로 작동하려면 아래 열을 포함한 CSV 파일이 필요합니다.
- 호선, 역명, 위도, 경도, 이용객수
